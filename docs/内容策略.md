# 知食奶爸 · 内容策略（差异化定位）

> 定位一句话：**用日本医学界的第一手资料，做中文圈稀缺的孕产育儿饮食科普，并做中日对照落地。**

## 一、为什么这个定位能赢

1. **信源稀缺**：中文孕产育儿内容 90% 转译英美（AAP/ACOG/WHO），日本体系在中文世界几乎无人系统性引入
2. **信源优质**：日本婴儿死亡率全球最低档，孕产管理和离乳食体系成建制、有官方指南背书
3. **壁垒真实**：需要同时具备①日语读文献能力 ②医学判断力 ③中文表达——三者兼备的人极少，这是别人抄不走的护城河
4. **受众双层**：在日华人家庭（刚需，原糖妈日记的老用户群）+ 国内对日式育儿感兴趣的家长（增量）

## 三、内容生产流程（每篇文章）

1. **选题**：从中文家长的真实痛点出发（社群提问、小红书热搜），不是"日本有什么就写什么"
2. **找日方信源**：指南 → 学会声明 → 医生科普，按这个顺序往下找
3. **交叉验证**：至少 2 个独立信源；与中国指南/WHO 有差异的地方，明确标注"日本的做法 vs 通行做法"
4. **重写 + 本地化**：用自己的话写，计量和食材换成中文家庭可得的（だし→香菇/虾皮高汤等替代）
5. **参考资料双语列出**：日文原名 + 中文说明，这本身就是差异化的可见证明

## 四、版权与合规红线

- ❌ **不整篇翻译转载**任何文章/指南（翻译权属于原作者）
- ✅ 事实、数据、医学结论不受版权保护——**用多信源事实自己重写**永远安全
- ❌ 不直接使用原文图表/插画，需要图就按《插画风格指南》自制
- ✅ 引用短句注明出处属合理引用
- ⚠️ 提及在世医生的观点时客观转述、注明姓名出处，不虚构背书、不暗示合作
- ⚠️ 涉及药品（如孕吐用药）只说"日本的处理思路"，不给具体用药建议

## 五、栏目化建议

- 固定 tag：`日本`（所有日本视角文章统一挂），积累后可做专题页
- 固定栏目模板：**「日本医生怎么说」**（单一主题的日本观点引入）、**「中日对照」**（同一问题两边做法对比 + 借鉴清单）
- 每篇文末固定一句："本文参考日文第一手资料写成"——反复锤打差异化认知
