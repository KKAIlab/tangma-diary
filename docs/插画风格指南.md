# 知食奶爸 · 插画风格指南

> 目标：所有配图看起来像"同一个人画的"，读者刷到缩略图就认出是你。
> 风格基底：编辑部钢笔线稿插画（黑白排线 + 固定吉祥物 + 品牌单点色）。

## 一、风格五条铁律

每张图都必须满足，这是"形成一套"的关键：

1. **白底黑线**：纯白背景，细钢笔线稿，阴影用排线（crosshatching），不用大面积填色、不用渐变
2. **固定主角**：吉祥物「碗芽」——杏色小碗当身体（黑白稿里涂黑或留白皆可，见下），头顶一颗双叶绿芽，白色圆眼睛，两条小细腿
3. **一图一梗**：每张图是一个视觉隐喻，不是场景堆砌（例：血糖过山车＝碗芽坐在馒头形状的过山车上）
4. **单点色**：全图黑白，只允许两个品牌色小面积出现——杏橙 #E8916F（重点物件/路线）、绿 #3E7A57（健康/正确的事物）
5. **大留白**：主体占画面 1/3～1/2，偏一侧，留白处放标注文字

## 二、吉祥物「碗芽」设定

- 身体：半圆小碗，碗足是两条短细腿，动作靠腿和身体倾斜表达
- 头顶：一根短茎 + 两片叶的绿芽（黑白稿里芽保持绿色，是全图唯一恒定的颜色锚点）
- 眼睛：两个白色圆点（涂黑身体时）或两个黑点（白描身体时），无嘴，情绪靠姿态
- 配角（可选）：围裙爸爸——极简笔画风格的男性，戴圆框眼镜，系围裙，偶尔挂听诊器
- 禁止：不要给碗芽加嘴、手套、鞋；不要画成 3D 或卡通上色风

**第一步先生成一张「角色设定图」**（三视图 + 5 个常用姿势：站立、举放大镜、端盘子、跌倒、欢呼），
以后每次出图都把这张图作为参考图（垫图）喂给 AI，角色就不会跑偏。

角色设定图 Prompt：

```
极简钢笔线稿角色设定图，白色背景。角色：一只可爱的小碗生物，
半圆形碗身，两条细短腿，头顶长着一株双叶嫩芽，圆点眼睛，没有嘴。
画出三视图（正面、侧面、背面）和5个姿势：站立、举着放大镜、
端着餐盘、惊讶跌倒、开心跳跃。黑白细线钢笔画，交叉排线阴影，
只有头顶嫩芽是绿色(#3E7A57)。编辑部插画风格，类似纽约客漫画。
character design sheet, minimalist pen and ink line art, fine crosshatching,
white background, editorial illustration, spot color green sprout only
```

## 三、万能出图 Prompt 模板

把【】里替换掉即可，其余原样保留（这段"风格锁"是一致性的来源）：

```
极简编辑部钢笔线稿插画，纯白背景，黑色细线，交叉排线做阴影，大量留白。
主角是固定角色「碗芽」：半圆小碗身体、两条细短腿、头顶双叶绿芽、圆点眼睛（参考垫图）。
画面内容：【碗芽正在做什么 + 一个视觉隐喻，例如：碗芽推着一块巨大的方糖上坡，
坡道由白米饭堆成】。
配色：整体黑白，只有【绿芽和一个关键物件】使用绿色(#3E7A57)，
【需要强调的物件/路径】使用杏橙色(#E8916F)，其余全部黑白。
构图：主体偏【左/右】下，占画面约1/3，上方和另一侧大量留白。
minimalist editorial pen-and-ink illustration, fine crosshatching, lots of white space,
single spot color accents, New Yorker cartoon style, no gradients, no 3D
```

**适用工具**：即梦、豆包、通义万相、Midjourney、GPT-4o/Nano Banana 生图都认这套描述。
支持垫图的工具（即梦/MJ/GPT-4o）务必带上角色设定图。

## 四、科普概念 → 视觉隐喻 速查表

出图前先把文章核心概念翻译成"一个画面"，这是这套风格的灵魂：

| 科普概念 | 视觉隐喻示例 |
|----------|--------------|
| 餐后血糖飙升 | 碗芽坐过山车，轨道是一根白面包 |
| 低GI主食替换 | 碗芽在天平两端比较白米饭砖块 vs 杂粮砖块 |
| 进餐顺序 | 三扇门排成队：蔬菜门、蛋白质门、主食门，碗芽按序通过 |
| 隐形糖 | 碗芽用放大镜看饮料瓶，瓶子里藏着一摞方糖 |
| 辅食第一口 | 巨大的勺子像跳板，碗芽站在勺尖准备起跳 |
| 铁储备耗尽 | 碗芽提着见底的油罐，罐身写着 Fe |
| 挑食对峙 | 碗芽和一颗西兰花隔桌对坐，中间沙漏在漏 |
| 喂养分工 | 一条虚线把餐桌分成两半，各站一边 |
| 月子餐迷思 | 一碗巨大的猪蹄汤冒着热气，碗芽在旁边举着小小的问号牌 |
| 生长曲线 | 碗芽沿着一条上坡的曲线爬山，插着小旗 |

公式：**抽象概念 = 日常物件的夸张化 + 碗芽和它的互动**。物件要巨大、角色要小，反差产生趣味。

## 五、文字标注系统（图上的彩色小标签）

参考图的点睛之笔。生成后在图上手动加标签（用醋园/Canva/PicsArt/手机备忘录标注都行），规则固定：

| 标签类型 | 样式 | 用途 |
|----------|------|------|
| 关键概念 | 杏橙描边圆角框 + 橙字 | 本图核心名词，每图最多1个 |
| 警示/误区 | 红色描边圆角框 + 红字 | "别这样做"，每图最多1个 |
| 疑问/思考 | 蓝色描边圆角框 + 蓝字 | 引导读者的问题 |

字体统一用一款圆体或手写体（如"站酷快乐体"，可免费商用），字号大到缩略图能读清。

## 六、尺寸规范

| 用途 | 尺寸 | 备注 |
|------|------|------|
| 公众号封面 | 900×383（2.35:1） | 主体放左1/3，右侧留白给标题 |
| 小红书封面 | 1242×1656（3:4） | 主体居中偏下，顶部放大字标题 |
| 网站文章配图 | 1200×675（16:9） | 放 `assets/images/`，文章内引用 |
| 网站分享卡 | 1200×630 | 已有模板 og-cover.png |

## 七、每篇文章的出图工作流（约10分钟）

1. 写完文章，摘出 1 个核心概念（就 1 个）
2. 查上面的速查表或造一个隐喻：概念 → 巨大物件 + 碗芽动作
3. 套万能模板生成 4 张，选构图最空、线最干净的 1 张
4. 加 1-2 个彩色标签（关键概念橙、误区红）
5. 导出两个尺寸（公众号横版 + 小红书竖版），文件存 `assets/images/`，命名 `文章slug-cover.png`

## 八、避免翻车

- 一张图只讲一个梗；想讲两个就画两张
- AI 画错芽的颜色/多出嘴巴 → 重roll，不要将就，角色一致性是命根子
- 别让 AI 直接生成中文字（常乱码），文字一律后期标注
- 保留每次的 prompt 和选中图，攒 20 张后你就有了自己的"风格语料库"，越垫越稳
